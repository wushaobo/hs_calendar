## 4. 流程用例

模拟条件：today = 2026-11-14（周六）；写入测试使用 2026-11-13（周五，工作日）。
`records.csv` 初始仅表头。

| # | 操作 | 预期 | 实际 | 结果 |
|---|---|---|---|---|
| W1 | `11/13请假` | 新增一行；CSV 按日期排序；回复「已记录 11/13 请假」+ 统计块 | 新增成功，表头与排序正确 | ✅ PASS |
| W2 | 同日再发 `11/13到岗` | 仍只有一行；状态变为 `on_site`；回复注明「覆盖原记录：请假」 | 一行，旧状态被识别并覆盖 | ✅ PASS |
| W3 | `取消11/13` | 删除该行，保留表头；回复「已取消 11/13 记录（原为到岗）」 | 行被删除，表头保留 | ✅ PASS |
| W4 | today=11/14 时发 `11/20到岗` | 首行「未来日期不可记录」；CSV 不变 | 拒绝，数据未变 | ✅ PASS |
| W5 | today=11/20 时补记 `11/14到岗` | 首行「非工作日不可记录」（11/14 是周六）；CSV 不变 | 拒绝，数据未变 | ✅ PASS |
| W6 | today=2028-01-10 时补记 `2027-06-01到岗` | 首行「2027 年节假日数据未配置，暂不可记录」；CSV 不变 | 拒绝，数据未变 | ✅ PASS |
| W7 | 关闭写文件能力后发 `11/13请假` | 明确「未能写入文件…未保存」；输出变更行 + 完整 CSV；不出现「已记录」 | 模板人工走查通过 | ✅ PASS（人工走查） |

补充核对：

- 同日期重复行：读取时取 `updatedAt` 最新一条并提示；写入时全量去重。
- 取消不存在的日期：回复 `11/13 没有记录，未做修改`，不报错。
- `records.csv` 缺失：按决策直接报错停止，不按空表继续。
- 失效记录：查询时追加「失效记录：…，建议清除」，不自动删除。
